## Per-product notes (all dated 2026-10-22)

1. Locally Uncensored. Created 2026-03-24. README is long, every release has an exe/AppImage/dmg/apk. Windows installers unsigned until SignPath cert arrives (README). Updates itself from GitHub. The "agent" is a real in-app tool-using agent; local model if the user picks one, but README says big frontier-class models need cloud keys or LU Cloud. Local-mode image/video needs a CUDA GPU through ComfyUI (they install it). Qwen-Image 2.1 weights are research-licence, non-commercial (README). The 2,470 stars is the most of any real desktop app here other than #11.
2. Raccord. Two repos share the name. `raccordai/raccordai` (MIT, raccord.ai) matches "desktop video studio, KIE.ai, built-in assistant". `raccordhq/raccord` (raccord.dev, "script supervisor for AI video", no licence field, last release July 2026 for a "wordpaper" tag) is a different project. Only 5 stars, repo 3.5 months old, solo-looking. Everything is billed through kie.ai; no local generation at all. Local SQLite; no account.
3. AI Desktop Studio. 1 star, repo created 2026-08-06, first release 1.0.0 on 2026-08-20 was named "scenario-studio" (renamed by 2.0.0 on 2026-09-08). Builds are unsigned (README). The "310 actions" is the project's own claim in llms.txt and the repo description, not independently counted. Licence blocks commercial use. Every generation needs the user's Scenario account and key. No local image/video models.
4. Velorn. Created 2026-03-08, 509 stars, many releases (0.1.x to 0.3.37), GPL-3.0. Hard dependency on a separately installed ComfyUI for ALL generation. "100+ MCP tools" is README wording (not counted). The built-in LLM Assistant looks like a LM Studio chat panel; I did not find evidence of a tool-calling in-app agent. Pinning this down further would need running the app.
5. BeatDesign. Created 2026-08-20. Not a desktop app yet: needs Node 22, pnpm and Chrome, and releases ship only agent-connector packages. Tool count is stated by the project (30 released / 38 source). Generation is only through the BeatAPI cloud provider, so it is cloud-billed. Marketing line "Open-source alternative to Higgsfield".
6. Comfy-Org/comfy-mcp. First-party per docs.comfy.org. Created 2026-07-01, beta by its own README. Dual licence means AGPL terms or buy a commercial licence. It was renamed from `comfy-local-mcp` (README upgrade section). Needs Python, comfy-cli and a ComfyUI install.
7. mike-nott/comfy-mcp. Created 2026-09-22, 1 star, 1 day of commits, no release tags. A personal tool; "private by construction" claim. Only two bundled models (Qwen Image 2.1, MiniMax H3), both need their weights installed by hand.
8. PotionUI. Created 2026-08-24, v0.0.x alpha, 47 stars, very active (commits today). It is a multi-user web server, not a desktop installer; README's install is git clone. Home site not reachable by curl from here, not confirmed.
9. SceneWorks. Created 2026-05-16, org-owned, 250 stars, releases every few days (15 releases listed), v0.10.0 published today. No repo description or homepage. Strongest "no Python, no Docker, native" claim. MCP lets outside agents generate; no in-app agent found. Local GPU only (cloud only via its own RunPod server mode).
10. ComfyAgent. The name is ambiguous. Matches the "desktop wrapper over ComfyUI, MCP server, MIT" description: IvenKooLab/comfy-agent. Other repos named like it: Getty/comfyagent (design/planning stage only, NO code, no licence), TheNinoDev/ComfyAgent (empty description, Python ComfyUI custom node, no licence), loke-jad/comfyagent (Chainlit chat, Apache-2.0), momang85/comfy-agent (MIT, custom-node bridge). Chosen one: Windows only, short-drama focus, strong Chinese-language slant (docs bilingual, LLM vendor list Chinese), 4 MCP tools. Requires the user's ComfyUI and ffmpeg on PATH.
11. Open Generative AI. The big star count (31k) is mostly the hosted-product marketing funnel: README has a White Label "$49/mo" pitch and utm links to muapi.ai. Created 2023-05-09 (older repo reused). Local mode is real (sd.cpp for SD1.5/SDXL/Z-Image) but video needs the user to install Wan2GP. Installers unsigned. Not a ComfyUI app.

## Ambiguity / things I could not confirm
- ComfyAgent is the least certain (see 10).
- beatapi.io/design and potionui.com did not return HTTP 200 to curl in this shell; project facts come from the GitHub READMEs, not those sites.
- Tool counts for Raccord, Locally Uncensored (none), Comfy-Org docs page, mike-nott total are not stated by the projects.
- I did not run any app. All "in-app agent" calls come from README/docs/source file names.

## 10-line summary
1. In-app agent that can run fully local: Locally Uncensored (Ollama/LM Studio/own engine; also cloud optional), PotionUI (Ollama or OpenRouter, alpha, browser app), AI Desktop Studio assistant can use Ollama but its generation is cloud-only. ComfyAgent's assistant uses cloud-vendor keys by default.
2. Cloud-only agent: Raccord (kie.ai key does generation and assistant) and Open Generative AI's Agent Studio (MuAPI).
3. No in-app agent, MCP only: BeatDesign, SceneWorks (7 tools), Comfy-Org/comfy-mcp (40 tools), mike-nott/comfy-mcp. Velorn only has a LM Studio chat panel plus "100+" MCP tools.
4. User must install ComfyUI themselves: Velorn (for ALL generation), ComfyAgent (Windows), Comfy-Org/comfy-mcp, mike-nott/comfy-mcp. Locally Uncensored installs and manages ComfyUI for the user. PotionUI makes ComfyUI optional.
5. No ComfyUI at all: SceneWorks (native, local GPU), Raccord, BeatDesign, AI Desktop Studio (all cloud), Open Generative AI (cloud + sd.cpp/Wan2GP).
6. Cloud-billed generation: Raccord (kie.ai), BeatDesign (BeatAPI), AI Desktop Studio (Scenario, noncommercial licence), Open Generative AI (MuAPI); Locally Uncensored/PotionUI/Velorn optionally.
7. Node graph visible: Raccord and BeatDesign (canvas), Velorn and ComfyAgent (ComfyUI editors), Open Generative AI (workflow studio). Hidden: Locally Uncensored, PotionUI, SceneWorks.
8. Actually expose an MCP server: Raccord, AI Desktop Studio (310 claimed, off by default), Velorn, BeatDesign, Comfy-Org, mike-nott, PotionUI, SceneWorks, ComfyAgent. Locally Uncensored does NOT (client only). Open Generative AI points at MuAPI's hosted MCP.
9. Licences: AGPL (LU, SceneWorks), GPL (Velorn, PotionUI), MIT (Raccord, mike-nott, ComfyAgent, Open Gen AI), Apache (BeatDesign), AGPL-or-commercial (Comfy-Org), PolyForm Noncommercial (AI Desktop Studio, not open source).
10. Red flags: very new and tiny (AI Desktop Studio 1 star, mike-nott 1 star, Raccord 5, ComfyAgent 30), alpha (PotionUI 0.0.x, BeatDesign 0.2 not a desktop app yet), Windows-only (ComfyAgent), unsigned installers (AI Desktop Studio, Open Generative AI, LU until SignPath).
