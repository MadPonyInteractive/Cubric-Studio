Two things found while reading the real code

The terminal question is smaller than it looks. The whole app is already monospace — JetBrains Mono, every surface, by PRODUCT.md principle 2. So "terminal" isn't a font change. It's only: a prompt glyph, a blinking caret, and whether the transcript is prose or a command log. VT323.woff2 is also already in assets/fonts/, but using it would be a second display face and principle 2 reserves that slot for the wordmark.

PRODUCT.md currently forbids the crew presence. Under “Mascots & logo”: “Away from the landing it is always Studio: a workspace does not swap in its own character, because the accent already states the subject.” The accent half of the decision matches principle 4 exactly. The mascot half reverses this line. It needs Fabio's sign-off and a PRODUCT.md edit, not a quiet override.
