What is from where

Header
The Stage. Cosmo at 20px beside the label. Never moves.
Transcript
The Ledge. Prose, bubbles for the user, quiet tool lines. No gutter, no log.
Ledge
The Ledge. One place to look for “who is working”. The guest slides in from the right over 280ms and only when its op actually ran; with reduced motion it just appears.
Terminal
Light. > and a block caret on the input. Nothing in the transcript.
Input
The panel's own. The standalone branch of MpiAgentChat already builds this row; panel mode renders it too and emits the same agent:send. Attachments (MPI-797 item 3) land here as numbered chips.
Top bar
Agent goes on the left: Agent · Flows · Record, so Flows lands dead centre again (a 1fr auto 1fr grid makes that exact, and pays back the half-button drift MPI-678 accepted). Same ghost as its neighbours — no fill, no border. Panel open = icon and label take --accent-heat, the app's existing toggled-ghost rule; the open panel itself is the loud signal. Icon chat, size:'sm', sets state.agentMode; the visible twin of the A hotkey.
Status bar
Untouched. Drawn as it is today — idle/remote scope, or the running job. The agent owns nothing in it.
Prompt box
The struck-out slot is where the Agent|Prompt toggle was. It goes; the box is generation-only, so you can generate on the right while Reel works on the left — the orange card in the gallery is that op.

One thing this drawing had to pick: the block caret. caret-shape:block is set on the real input and falls back to the native bar where the engine lacks it; the drawn block shows only while the field is empty and unfocused. If the bar is fine in the app, the implementer skips the fake entirely.
